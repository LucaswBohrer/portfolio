# Lucas Welter Bohrer — Portfolio

Personal portfolio site: AI & Technology Engineer. Built with Next.js, React and Tailwind CSS.

## Features

- Tab-based navigation: Home, About, Projects, Experience, Contact
- Bilingual (PT/EN) with persisted language preference
- Dark professional theme with animated components (aurora background, spotlight cards, split-text hero, terminal motifs)
- Curated GitHub projects showcase
- Downloadable résumé (PDF)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Deploy

Deployed on Vercel. Every push to `main` triggers a new deployment.
